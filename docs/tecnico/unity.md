# Unity — projeto independente

Existe um projeto Unity **à parte**, na pasta:

`C:\dev\unbox-fighters-unity`

É um projeto **Unity 6** (6000.5.5f1) com a tela de montagem (caixas, 3 cartas, arrastar, LUTAR).

- **Não depende** deste repositório Godot: tem as próprias imagens, sons, dados e cena.
- Você pode abrir só o Unity e editar / jogar a montagem.
- O jogo em Godot neste repo continua existindo em paralelo.

Como abrir: leia o `README.md` dentro de `unbox-fighters-unity`.

A cena Unity já mostra fundo, cartas, prateleira e caixas no editor (sem precisar apertar Play).
