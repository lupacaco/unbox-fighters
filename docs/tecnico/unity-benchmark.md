# Unity — cópia para benchmark

Existe uma pasta irmã **fora** deste repositório Godot:

`C:\dev\unbox-fighters-unity`

- O jogo “oficial” de desenvolvimento continua sendo o **Godot** neste repo.
- A cópia Unity **não substitui** o Godot; não apague este projeto.
- Detalhes de abertura e bootstrap: leia o `README.md` dentro de `unbox-fighters-unity`.
